# Security Policy

## Supported Versions

Security fixes are generally applied to the actively maintained version of
CodeCabinate.

| Version | Supported |
|---------|-----------|
| Latest  | Yes       |
| Older versions | No |

## Reporting a Vulnerability

Please do not publicly report security vulnerabilities through GitHub Issues
or Pull Requests.

Instead, report security vulnerabilities privately to:

**Email:** sachinchau444@gmail.com
Please include:

- A description of the vulnerability.
- Steps to reproduce the issue.
- The potential impact.
- Any proof of concept, if available.
- Suggested mitigation, if known.

## Response

The maintainers will review security reports and may contact you for
additional information.

Please allow reasonable time for investigation and remediation before
public disclosure.

## Responsible Disclosure

We request that security researchers:

- Avoid accessing or modifying data that does not belong to them.
- Avoid disrupting the availability of the service.
- Avoid exploiting vulnerabilities beyond what is necessary to demonstrate
  the issue.
- Do not publicly disclose the vulnerability before coordinating with the
  maintainers.

## Security Updates

Confirmed security vulnerabilities may be addressed through security
patches or new releases.

Security advisories may be published when appropriate.
